## 关键模式（必须遵守）

### 1. transform 旋转公式
从中心点旋转的元素的 CSS 必须使用此顺序：
```css
transform: translateY(-50%) rotate(var(--angle));
transform-origin: 0 50%;
/* 先平移再旋转，确保从圆心发出 */
```

### 2. 工具注册方式
每个工具在 IIFE 末尾注册：
```javascript
window.FixedToolRegistry.register({
  id: "tool-id",
  name: "工具名",
  icon: "🚩",
  desc: "描述",
  mount: mountFunction
});
```
mount 函数签名：`mount(container, helpers, options)`

### 3. CSS 类名前缀
| 前缀 | 用途 |
|------|------|
| `.semaphore-*` | 旗语工具专属 |
| `.morse-*` | 莫尔斯工具专属 |
| `.radix-*` | 进制转换专属 |
| `.tool-*` | 通用工具类 |

### 4. 主题变量（公共 token）
```css
--primary          /* 主色（蓝） */
--primary-soft     /* 主色柔和 */
--primary-glow     /* 主色发光 */
--danger           /* 危险/强调（红） */
--danger-soft      /* 红色柔和 */
--surface-1/2/3    /* 背景层次 */
--line / --line-strong  /* 边框 */
--text-main / --text-sub /* 文字 */
```

### 5. 动画 ease 曲线
- 普通过渡：`transition: all .16s ease`
- 悬停上浮：`transform: translateY(-2px)` + 阴影
- 按下缩小：`transform: scale(0.98)`
- 弹入吸附：`cubic-bezier(0.34, 1.56, 0.64, 1)`
- 脉冲闪烁：`@keyframes morsePulse`（scale + box-shadow）

## 技术要求

- **纯静态**：HTML + CSS + Vanilla JS，无框架
- **禁止 alert**：统一用自定义 toast
- **移动端**：按钮点击区 >= 44px
- **响应式**：`@media (max-width: 840px)` 断点

## CSS 技巧

- `aspect-ratio: 1` 强制正方形
- `border-radius: 999px` 完美圆形
- `color-mix(in srgb, var(--primary) 76%, white 24%)` 调色混合
- `overflow: visible` + `transform-origin` 控制旋转轴心
- `filter: blur()` + 伪元素 实现发光效果

## 文件组织架构

### text-tools/ 模式（当前主力）

```
text-tools/
├── text-tools.html          # 工具主页（所有工具的容器）
├── text-tools.css           # 所有工具共享样式（含 .semaphore-* 等）
└── tools/
    ├── bundle.js            # 所有工具 JS 合并打包（不要手动修改）
    ├── build-bundle.ps1     # 打包脚本
    ├── semaphore.js         # 旗语工具（单独源文件）
    ├── morse.js             # 莫尔斯工具
    └── [tool].js            # 新工具按相同方式添加
```

**添加新工具流程：**
1. 在 `tools/` 下创建 `[tool].js`，按 `mount()` + `FixedToolRegistry.register()` 格式导出
2. 修改 `text-tools.html` 添加入口卡片（参考现有卡片结构）
3. 运行 `tools/build-bundle.ps1` 重新打包 bundle.js
4. 更新 `index.html` 添加链接

**禁止直接修改 bundle.js**，所有改动都在独立工具文件中。

### 样式分层

| 文件 | 内容 |
|------|------|
| `styles.css` | 全局基础样式 |
| `text-tools/text-tools.css` | 所有工具共享样式（含 .tool-* 前缀） |
| 各工具 `<style>` | 仅该工具专属的 isolated 样式 |

原则：共享 token 写在 text-tools.css，工具专属样式也写在 text-tools.css（按前缀区分）。

## 常见错误

1. **transform 顺序错误** → 射线/指针偏移不出自圆心
2. **改主题 token 没同步** → 页面风格分裂
3. **alert 使用** → 强制改为 toast
4. **未阅读现有实现就重写** → 破坏原功能
